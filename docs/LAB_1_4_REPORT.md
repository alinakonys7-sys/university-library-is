# Лабораториялық жұмыстар №1–4 бойынша есеп
**Тақырып:** Университеттің электрондық кітапханасын басқару ақпараттық жүйесі

## №1. Жобалау және орта дайындау
**Мақсаты:** кітапхана ақпараттық жүйесінің құрылымын жобалау.
**Нәтиже:** `Category`, `Author`, `Book` кестелері таңдалды; ER-диаграмма `docs/er_diagram.png` файлына жасалды. `app/database`, `app/routers`, `app/frontend` модульдері және `requirements.txt`, `.gitignore` дайындалды.
**Ескерту:** VS Code/Cursor және GitHub репозиторийін өз компьютеріңізде баптау керек.

## №2. Реляциялық база және ORM
**Мақсаты:** SQLite кестелерін SQLModel арқылы жасау.
**Нәтиже:** `models.py` ішінде 3 кесте, сыртқы кілттер, Relationship анықталды; `db.py` базаны жасайды; `seed.py` 4 категория, 4 автор, 5 кітап енгізеді. `python seed.py` орындағанда `database.db` пайда болады.

## №3. REST API
**Мақсаты:** FastAPI арқылы кітаптарды оқу және қосу.
**Нәтиже:** `GET /books`, `GET /books/{book_id}`, `POST /books` маршруттары, `Depends(get_session)`, Pydantic валидациясы және Swagger құжаттамасы жасалды. Жоқ кітапқа 404, жарамсыз дерекке 422, сәтті қосуға 201 қайтарылады.

## №4. CRUD және сүзгілеу
**Мақсаты:** кітап мәліметін ішінара жаңарту, өшіру, іздеу.
**Нәтиже:** `BookUpdate` схемасы, `PATCH /books/{book_id}`, `DELETE /books/{book_id}` және `GET /books` ішіндегі `search`, `min_year`, `max_year`, `category_id`, `min_copies`, `max_copies` сүзгілері жасалды.

**Тексеру сценарийлері:**
1. GET `/books?search=Python` — тек сәйкес кітаптар.
2. PATCH `/books/1` және `{"copies":10}` — тек copies өзгереді.
3. GET `/books/1` — copies=10.
4. POST арқылы тест кітап қосу, DELETE арқылы оның id мәнін өшіру — 204.
5. Өшірілген кітапқа PATCH — 404.
6. PATCH `{"copies":-1}` — 422.

**Қорытынды:** Алғашқы төрт лаборатория үшін деректер қоры мен API негізі дайындалды. Нақты жұмысын көрсету үшін локалды серверді іске қосып, Swagger нәтижелерінің скриншоттарын түсіру қажет. Кейін №5-те Streamlit, №6-да Docker, №7-де pytest қосылады.
