# Лабораториялық жұмыстар №5–7 бойынша есеп

**Жоба:** Университеттің электрондық кітапханасы

## №5. Streamlit веб-интерфейсі
**Мақсаты:** пайдаланушыға кітаптарды басқаруға арналған веб-интерфейс құру.  
**Орындалғаны:** `app/frontend/ui.py` ішінде кітаптарды көрсету, атауы мен категориясы бойынша іздеу, жыл бойынша сүзгілеу, POST арқылы қосу, PATCH арқылы дана санын өзгерту және DELETE арқылы жою формалары жазылды. Streamlit HTTP сұраныстарын `requests` арқылы FastAPI серверіне жібереді.

**Тексеру:** `python -m streamlit run app/frontend/ui.py` командасымен сайтты ашып, кітап қосу, іздеу және жоюды көрсету. Интерфейс: `http://localhost:8501`.

## №6. Docker және Docker Compose
**Мақсаты:** бэкенд пен фронтендті бөлек контейнерлерде бірге іске қосу.  
**Орындалғаны:** `Dockerfile`, `Dockerfile.frontend`, `docker-compose.yml`, `.dockerignore` файлдары қосылды. `backend` 8000 портында, `frontend` 8501 портында жұмыс істейді. `BACKEND_URL=http://backend:8000`. SQLite файлы жоғалмауы үшін `library_data` volume қолданылды.

**Тексеру:** Docker Desktop қосулы кезде `docker compose up --build`; сайт `http://localhost:8501`, Swagger `http://localhost:8000/docs`.

## №7. Автоматты тестілеу және қорғау
**Мақсаты:** REST API дұрыстығын автоматты тексеру.  
**Орындалғаны:** `tests/test_api.py` ішінде pytest және TestClient көмегімен GET, POST, сүзгі, PATCH, DELETE, 404 және 422 жағдайлары қамтылды. Тесттер нақты пайдаланушы базасын өзгертпейтін уақытша SQLite базасын пайдаланады.

**Тексеру:** `python -m pytest -v` — тесттер орындалады. GitHub-та README, ER-диаграмма, бастапқы код және commit тарихы көрсетіледі.

## Қорытынды
№1–7 жұмыстарына арналған жоба файлдары дайындалды. Оқытушыға көрсетпес бұрын Docker, Streamlit және pytest нәтижелерін өз компьютеріңізде іске қосып тексеріп, скриншот түсіру керек. GitHub-қа жүктеу пайдаланушы аккаунты арқылы орындалады.
